# NLTCP/PAM4 神经网络融合实验

> 状态：探索性复现。使用 NN 文件夹中的 19 组历史捕获，不是独立新采集的最终测试集。

## 实验口径

- 输入为助教接收流程中的 CAP 解调后符号率复数流 `datarx1/2`；I/Q 分别作为实值特征。
- 每个符号使用中心 25 符号窗，固定 RC 为 80 个储备池节点、泄漏率 0.7、谱半径 0.9；单支读出使用岭回归。
- 按时间顺序划分：训练 10,000 符号、验证 10,000 符号、其余为测试；MLP 用验证 MSE 早停。
- 计分沿用助教 `NLTCP_demodulation.m` 的 PAM6 最近邻量化和差分 PAM4 解码，对 I/Q 比特错误求平均。
- 助教原始 RC 单支 MATLAB 文件 `RClzl_w2s.m` 未在当前 NN 文件夹材料中找到。因此 Python 版依据同学报告中的参数实现，并通过独立 MATLAB 等式核验；不能称为原 MATLAB 文件逐行移植。

## 当前结果

19 组捕获、3 个随机种子，共 57 次配对测试结果的平均 BER：

| 接收结果 | 测试 BER 均值 |
| --- | ---: |
| 验证集选出的最佳单支 RC | 1.3140e-2 |
| 双支输出 MLP | 1.0586e-2 |
| 仅最佳分支输出的同结构 MLP | 1.3288e-2 |
| 原 MATLAB 符号 LMS 基线 | 2.5433e-3 |

双支 MLP 相对最佳单支 RC 平均降低 `19.34%`，57/57 次配对结果均有下降；相对仅最佳分支输入的同结构 MLP 平均降低 `20.24%`，57/57 次均有下降。相对原 MATLAB 符号 LMS，逐次配对的平均 BER 高 `461.50%`，仅 3/57 次低于 LMS；两者平均 BER 直接相除约为 `4.16` 倍。也就是说，当前结果支持“小型 MLP 能改善现有 RC 输出融合”，但不支持“该神经网络接收机优于原链路”。

相对变化采用逐捕获、逐种子配对后再取算术平均，而非用汇总 BER 相除。逐次结果见 `results/per_capture_seed.csv`，均值及胜出次数见 `results/summary.json`。

## RC 实现核验

助教 NN 文件夹没有找到同学报告所述的 `RClzl_w2s.m`，因此不能做原文件逐行翻译。本目录的 `rc_single.py` 按报告描述的 25 符号窗、80 节点、泄漏率 0.7、谱半径 0.9 和岭系数 `1e-5` 实现单支 RC。独立 MATLAB/Python 等式核验使用同一输入与固定矩阵，状态、读出矩阵和预测最大绝对误差分别约为 `4.2e-15`、`1.4e-13`、`6.3e-13`；这验证数值运算实现一致，不代表复现了缺失的助教源文件或其随机数初始化。

结果解释必须分开两种基线：

- 相对最佳单支 RC 的降低率：`(BER_RC - BER_MLP) / BER_RC`。
- 相对原符号 LMS 链路的变化率：`(BER_LMS - BER_MLP) / BER_LMS`。负值表示 MLP 的 BER 更高。
